# 初中英语词汇复习工具 — 需求文档

> 版本：v1.0（已实现）
> 日期：2026-08-28

---

## 1. 项目背景与目标

初中生（或家长/老师）手头有按单元整理的英语词汇 Excel 表，需要一个工具：

- **导入** Excel 词汇表，无需手工录入；
- 按**单元**组织、浏览、复习单词；
- 单词可**点击发音**（英文朗读，支持美式/英式口音）；
- 通过**中英文连线**游戏巩固记忆，带正确/错误/完成提示音；
- 内置**人教版初中英语示例词库**（七上、八上、八下），开箱即用；
- 纯本地运行，无需安装、无需注册，保护数据隐私。

---

## 2. 运行形态

- 一个**纯前端网页应用**：双击 `index.html` 即可在浏览器中使用（或用 `python3 -m http.server` 启动本地服务）。
- 数据保存在浏览器本地（IndexedDB / localStorage），不上传任何服务器。
- 发音使用浏览器内置 **Web Speech API**（`speechSynthesis`），无需音频文件。
- 第三方库（Vue 3、Element Plus、SheetJS）均**本地引入**（`lib/` 目录），离线可用。

---

## 3. 技术栈

| 项 | 选型 | 说明 |
|------|------|------|
| 框架 | **Vue 3**（全局构建 `vue.global.prod.js`，免构建） | 组合式 API，单文件 `js/app.js` |
| UI 组件库 | **Element Plus 2.8**（本地引入 + 中文语言包） | 下拉、弹窗、按钮、表格、进度条、消息提示等 |
| Excel 解析 | **SheetJS**（`xlsx.full.min.js`，本地引入） | 前端解析/生成 xlsx |
| 发音 | Web Speech API（`speechSynthesis`） | 浏览器内置，支持口音/语速 |
| 存储 | IndexedDB（词库数据）+ localStorage（设置项） | 容量大，可存多个词库 |
| 连线 | SVG 画线 | 轻量、易实现连线与变色 |
| 提示音 | Web Audio API 实时合成 | 无需音频文件 |

> 项目无构建步骤，所有依赖放在 `lib/`，双击 `index.html` 即可运行。

## 4. 功能需求

### 4.1 Excel 导入

| 编号 | 需求 | 说明 |
|------|------|------|
| F1-1 | 支持格式 | `.xlsx`、`.xls`（使用 SheetJS 解析） |
| F1-2 | 模板下载 | 提供"下载导入模板"按钮，内含表头与示例行 |
| F1-3 | 列字段 | 单元、单词、音标、词性、中文释义、例句（英文）、例句翻译；音标/词性/例句可留空 |
| F1-4 | 多册管理 | 支持导入多本教材/多个词库，可切换、删除 |
| F1-5 | 数据校验 | 缺少"单词/中文释义"的行给出提示并跳过；自动定位表头行 |
| F1-6 | 导入预览 | 导入后先预览解析结果（条数、单元列表、提示信息），确认后保存（`el-dialog`） |
| F1-7 | 追加/覆盖 | 同名词库重复导入时，可选择"追加（自动去重）"或"覆盖" |
| F1-8 | 表头兼容 | 表头支持中英文别名（单元/Unit、单词/英文/Word、释义/中文/Meaning 等），顺序灵活 |

### 4.2 内置示例词库

| 编号 | 需求 | 说明 |
|------|------|------|
| F2-1 | 示例词库 | 内置人教版初中英语三册：**七年级上册**（138 词）、**八年级上册**（286 词）、**八年级下册**（335 词） |
| F2-2 | 一键载入 | 词库管理页"示例词库"弹窗，可按册**直接载入**或**下载 Excel** |
| F2-3 | 数据同源 | 应用内数据（`js/samples-g*.js`）与可下载 xlsx 由同一数据源生成（`tools/gen-sample.js`），保证一致 |
| F2-4 | 字段完整 | 每词含单元、单词、IPA 音标、词性、中文释义、英文例句、例句翻译 |
| F2-5 | 去重 | 同册内无重复单词（跨单元重复词已剔除） |

### 4.3 词库与单元浏览

- 词库选择器（`el-select` 下拉，自定义浮层样式）。
- 词库卡片显示：词数、已掌握数、错词数、单元数、掌握进度条（`el-progress`）。
- 可按单元筛选，也可"全部单词"或"错词本"模式。
- 支持备份导出（JSON）/ 备份导入 / 清空数据（均带 `ElMessageBox` 二次确认）。

### 4.4 分单元复习（单词卡片模式）

- 卡片正面：**单词 + 音标 + 词性**，带 🔊 发音按钮。
- 点击卡片翻转：显示**中文释义 + 例句 + 例句翻译**，例句可发音。
- 底部操作（`el-button`）：
  - `上一个` / `下一个`；
  - `认识`（标记已掌握）/ `不认识`（加入错词本）；
  - `随机顺序` / `顺序播放` 切换；
  - `自动播放`（每隔 N 秒自动朗读并翻卡，间隔 2/3/5/8 秒可调）。
- 进度条显示"当前位置 / 总数"（`el-progress`）。
- 大字号设计：单词 76px、释义 52px（移动端 52/38px），长单词自动换行。

### 4.5 发音功能

| 编号 | 需求 | 说明 |
|------|------|------|
| F4-1 | 单词发音 | 点击 🔊 朗读单词 |
| F4-2 | 例句发音 | 卡片背面例句可朗读 |
| F4-3 | 口音切换 | **美式发音 / 英式发音**（`el-select`），实时生效 |
| F4-4 | 语速调节 | 慢（0.7）/ 正常（1）/ 快（1.3）三档 |
| F4-5 | 容错 | 浏览器不支持语音合成时，按钮置灰并提示 |
| F4-6 | 本地语音优先 | 优先选用系统本地语音（`localService=true`），网络语音（如 Google 在线语音）易静默失败，降级为候选 |
| F4-7 | 发声看门狗 | 朗读后若 700ms 内未触发 `onstart`（语音发不出声），自动取消并尝试下一个候选语音 |
| F4-8 | 候选链降级 | 本地英式 → 网络英式 → 本地美式 → 网络美式 → 仅设 lang 兜底，保证一定有声音 |
| F4-9 | 长文本补丁 | Chrome 长文本朗读约 15 秒后自动暂停的 bug，定时 `resume()` 规避 |
| F4-10 | 竞态处理 | `cancel()` 后延迟发起 `speak()`，避免切换口音/语音时静默丢音 |
| F4-11 | 调试接口 | 控制台可调用 `VocabSpeech.diagnose('uk')` 查看候选语音链 |

> 说明：音色取决于操作系统/浏览器自带语音。Chrome/Edge 效果较好；macOS 英式典型语音为 Daniel/Kate/Serena，Windows 为 George/Hazel。

### 4.6 中英文连线练习

- 从所选范围（全部/单元/错词本）随机抽取 **N 个单词**（默认 10，可选 5/10/15/20）。
- 左侧列：英文单词（带 🔊）；右侧列：打乱顺序的中文释义。
- 操作：点击一个英文，再点击对应中文，建立连线（SVG 画线）。
- 反馈：
  - 配对正确：连线变绿锁定，播放**正确提示音**（清脆上行"叮咚"双音）；
  - 配对错误：连线变红抖动后消失，计入错误数，播放**错误提示音**（低沉"嘟嗡"双音）。
- 全部完成：播放**完成提示音**（四音上行琶音），显示用时、错误数、得分。
- 结果页可"再来一组"或"返回设置"。
- 错题自动加入错词本。

### 4.7 错词本与学习记录

- 每个单词状态：未学 / 已掌握 / 错词。
- 错词本（`el-table` 斑马纹表格）：错词列表、搜索、朗读、标记已掌握、移出、清空。
- 错次用 `el-tag` 红色标签显示。
- 各单元掌握进度条（`el-progress`）。
- 支持"复习错词"（跳转卡片复习）和"连线练习"（针对错词出题）。

| 单元 | 单词 | 音标 | 词性 | 中文释义 | 例句 | 例句翻译 |

| Unit 1 | good | /ɡʊd/ | adj. | 好的 | Good morning! | 早上好！ |

## 6. 非功能需求

- **兼容性**：Chrome / Edge 最新版为主（发音功能依赖系统语音）；Safari 基本可用。
- **数据存储**：IndexedDB（词库数据）+ localStorage（口音、语速、自动播放间隔等设置）。
- **数据安全**：提供"导出备份 JSON / 导入备份 / 清空数据"，危险操作均有二次确认。
- **隐私**：全部数据本地处理，无网络请求（第三方库均本地引入）。
- **界面**：Element Plus 组件 + 自定义卡片/连线样式，简洁清爽，适合学生使用。
- **响应式**：PC 与平板为主，手机端基础适配（控制栏换行、下拉宽度自适应、卡片字号缩放）。

---

## 7. 页面结构（单页应用，顶部 Tab 切换）

1. **词库管理**：导入 Excel、下载模板、示例词库（载入/下载）、词库卡片列表/切换/删除、备份导入导出、清空数据。
2. **单词复习**：选词库/范围/口音/语速 → 卡片翻转复习 + 发音 + 自动播放。
3. **连线练习**：选词库/范围/每组数量 → 出题 → SVG 连线 → 提示音 → 结果页。
4. **错词本**：单元进度、错词表格、搜索、朗读、复习/连线/清空。
