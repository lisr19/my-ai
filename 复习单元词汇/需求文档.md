# 初中英语词汇复习工具 — 需求文档

> 版本：v0.1（待核实）
> 日期：2026-08-27

---

## 1. 项目背景与目标

初中生（或家长/老师）手头有按单元整理的英语词汇 Excel 表，需要一个工具：

- **导入** Excel 词汇表，无需手工录入；
- 按**单元**组织、浏览、复习单词；
- 单词可**点击发音**（英文朗读）；
- 通过**中英文连线**游戏巩固记忆；
- 纯本地运行，无需联网、无需安装、无需注册，保护数据隐私。

---

## 2. 运行形态

- 一个**纯前端网页应用**：双击 `index.html` 即可在浏览器中使用（或用一条命令启动本地服务）。
- 数据保存在浏览器本地（IndexedDB / localStorage），不上传任何服务器。
- 发音使用浏览器内置 **Web Speech API**（`speechSynthesis`），无需联网、无需音频文件。

---

## 3. 功能需求

### 3.1 Excel 导入

| 编号 | 需求 | 说明 |
|------|------|------|
| F1-1 | 支持格式 | `.xlsx`、`.xls`（使用 SheetJS 解析） |
| F1-2 | 模板下载 | 页面提供"下载导入模板"按钮，内含表头与示例行 |
| F1-3 | 列字段 | 单元、单词、音标、词性、中文释义、例句（英文）、例句翻译；后 4 项可留空 |
| F1-4 | 多册管理 | 支持导入多本教材/多个词库（如"七上""七下"），可切换、删除 |
| F1-5 | 数据校验 | 缺少"单词/中文/单元"的行给出错误提示并跳过；重复单词提示 |
| F1-6 | 导入预览 | 导入后先预览解析结果（条数、单元列表），确认后保存 |
| F1-7 | 追加/覆盖 | 同一词库重复导入时，可选择"追加"或"覆盖" |

### 3.2 词库与单元浏览

- 词库选择器（七上 / 七下 / …）。
- 单元列表（Unit 1、Unit 2…），显示每单元单词数、学习进度。
- 可按单元筛选，也可"全部单词"模式。
- 支持搜索单词/中文。

### 3.3 分单元复习（单词卡片模式）

- 卡片正面：**单词 + 音标 + 词性**，带 🔊 发音按钮。
- 点击卡片（或按钮）翻转：显示**中文释义 + 例句 + 例句翻译**，例句可发音。
- 底部操作：
  - `上一个` / `下一个`；
  - `认识`（标记已掌握）/ `不认识`（加入错词本）；
  - `随机顺序` / `顺序播放` 切换；
  - `自动播放`（每隔 N 秒自动朗读并翻卡，间隔可调）。
- 进度条显示"当前位置 / 本单元总数"。

### 3.4 发音功能

| 编号 | 需求 | 说明 |
|------|------|------|
| F4-1 | 单词发音 | 点击 🔊 朗读单词 |
| F4-2 | 例句发音 | 卡片背面例句可朗读 |
| F4-3 | 口音切换 | 美式发音 / 英式发音（选择可用语音 voice） |
| F4-4 | 语速调节 | 慢 / 正常 / 快 三档 |
| F4-5 | 容错 | 浏览器不支持语音合成时，按钮置灰并提示 |

> 说明：Web Speech API 的音色取决于操作系统/浏览器自带语音，Chrome/Edge 效果较好。

### 3.5 中英文连线练习

- 从所选单元（或错词本）随机抽取 **N 个单词**（默认 10，可选 5/10/15/20）。
- 左侧列：英文单词（带 🔊）；右侧列：打乱顺序的中文释义。
- 操作：点击一个英文，再点击对应中文，建立连线（Canvas/SVG 画线）。
- 反馈：
  - 配对正确：连线变绿，锁定；
  - 配对错误：连线变红抖动后消失，计入错误数。
- 完成后显示结果：**用时、正确率、错误单词列表**。
- 错题可"再来一组"或自动加入错词本。

### 3.6 学习记录（基础版）

- 每个单词状态：未学 / 已掌握 / 错词。
- 错词本：集中复习不认识的词，支持"移出错词本"。
- 简单统计：各单元掌握进度条、累计学习数。

## 4. Excel 模板格式

| 单元 | 单词 | 音标 | 词性 | 中文释义 | 例句 | 例句翻译 |
|------|------|------|------|----------|------|----------|
| Unit 1 | good | /ɡʊd/ | adj. | 好的 | Good morning! | 早上好！ |
| Unit 1 | morning | /ˈmɔːnɪŋ/ | n. | 早晨 | Good morning! | 早上好！ |
| Unit 2 | spell | /spel/ | v. | 拼写 | How do you spell it? | 你怎么拼写它？ |

- 表头名称可兼容常见写法（如"单元/Unit""单词/英文""中文/释义"），导入时自动映射。
- 第一个工作表（sheet）为词汇表。

## 5. 非功能需求

- **兼容性**：Chrome / Edge 最新版为主（发音功能依赖系统语音）；Safari 基本可用。
- **数据存储**：IndexedDB（词库数据）+ localStorage（设置项）；提供"导出备份 JSON / 清空数据"。
- **隐私**：全部数据本地处理，无网络请求。
- **界面**：简洁清爽，适合学生使用；卡片式布局；PC 与平板均可使用（手机端基础适配）。

## 6. 技术方案（建议）

| 项 | 选型 | 理由 |
|------|------|------|
| 页面 | 原生 HTML + CSS + JavaScript（无构建步骤） | 双击即用，与 `auto-form-filler` 风格一致，零依赖安装 |
| Excel 解析 | SheetJS（`xlsx`，本地引入） | 前端解析 xlsx 事实标准 |
| 发音 | Web Speech API（`speechSynthesis`） | 浏览器内置，免费离线 |
| 存储 | IndexedDB（词库） | 容量大，可存多个词库 |
| 连线 | SVG 画线 | 轻量、易实现连线与变色 |

> 备选：若希望界面更丰富，可用 Vue 3（CDN 引入，免构建）。**默认按原生 JS 方案开发**，如你偏好 Vue 请告知。

## 7. 页面结构（单页应用，顶部 Tab 切换）

1. **词库管理**：导入 Excel、下载模板、词库列表/切换/删除、导出备份。
2. **单词复习**：选单元 → 卡片翻转复习 + 发音。
3. **连线练习**：选单元/错词本 → 出题 → 连线 → 结果页。
4. **错词本**：错词列表、快速复习、移除。

---

## 8. 开发计划（建议顺序）

1. **M1**：项目骨架 + Excel 导入/解析 + 模板下载 + IndexedDB 存储 + 词库管理页。
2. **M2**：单词卡片复习页（翻转、上下个、进度）+ 发音（单词/例句、口音、语速）。
3. **M3**：中英文连线游戏（出题、画线、判分、结果）。
4. **M4**：错词本 + 学习统计 + 样式打磨 + 自测。
