# 复习单元词汇 — 初中英语词汇复习工具

纯前端、纯本地运行的英语词汇复习网页应用：导入按单元整理的 Excel 词汇表，即可进行
**单词卡片复习**（点击发音、翻面看释义）和**中英文连线练习**，错词自动进入错词本。

- 无需联网、无需安装、无需注册，数据全部保存在浏览器本地（IndexedDB）
- 发音使用浏览器内置 Web Speech API（美式/英式、语速可调）
- Vue 3 + SheetJS，均为本地文件，零构建步骤

## 快速开始

方式一（推荐）：双击打开 `index.html`（Chrome / Edge 效果最佳）。

方式二（本地服务，兼容性更好）：

```bash
cd 复习单元词汇
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

首次使用：点击「✨ 一键载入示例词库」（人教版七年级上册，约 130 词）立即体验；
也可以先「📄 下载导入模板」，按模板整理自己的词汇 Excel 后导入。

## 功能

| 模块 | 功能 |
|------|------|
| 词库管理 | Excel 导入（.xlsx/.xls）、导入预览、追加/覆盖、多词库切换/删除、模板下载、示例词库、JSON 备份导出/导入、清空数据 |
| 单词复习 | 卡片翻转（单词+音标+词性 ↔ 释义+例句）、单词/例句发音、上一个/下一个、认识/不认识、随机/顺序、自动播放（间隔可调）、进度条、键盘快捷键 |
| 连线练习 | 按单元/错词本出题，每组 5/10/15/20 词，SVG 连线，正确变绿锁定、错误闪红，结果页显示用时/正确率/错词，错词自动入错词本 |
| 错词本 | 错词列表、搜索、单元掌握进度、标记掌握/移出/清空、一键跳转复习或连线 |

快捷键（复习页）：`空格` 翻面 · `←`/`→` 切换单词 · `1` 认识 · `2` 不认识

## Excel 格式

第一个工作表，表头包含以下列（表头名兼容常见写法，后 4 列可留空）：

| 单元 | 单词 | 音标 | 词性 | 中文释义 | 例句 | 例句翻译 |
|------|------|------|------|----------|------|----------|
| Unit 1 | good | /ɡʊd/ | adj. | 好的 | Good morning! | 早上好！ |

缺少「单词/中文释义」的行会跳过并提示；重复单词自动跳过。

## 说明

- 发音音色取决于操作系统自带语音，Chrome/Edge 效果较好；不支持语音合成的浏览器发音按钮自动置灰。
- 数据按浏览器存储，清理浏览器数据会丢失词库，重要数据请用「导出备份」保存 JSON。
