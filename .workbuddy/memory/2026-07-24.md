## TTS 换为 macOS native + 头像问题修复
- **头像问题**：之前的 public/avatar-joy.png 在 Vite 5.4 dev 模式下被 SPA fallback 拦截，访问返回 HTML。改为把图片移到 src/assets/ 通过 ESM import 打包（Vite 自动处理），同时把图片缩到 512x471 大小（284KB）。
- **TTS 切换**：把 Edge TTS（之前英文问题 + 符号读出问题）整个换掉。后端用 macOS `say -v Tingting` 生成 AIFF，再用 `afconvert` 转 AAC/M4A（MIME: audio/mp4）。
- **强力清洗 markdown**：后端 /api/tts 收到文本后正则剥离 `**`/`*`/删除线/链接/图片/列表/颜文字/emoji/特殊符号等，再交给 TTS，绝不让 TTS 读到任何 markdown 标记。
- **TTS 不再打断**：useEdgeTTS hook 改为队列模式：每次 speak 不再 abort 当前的，而是排队顺序播放。这样流式输出时第一次 speak(部分) 播完后，剩余文字的 speak 自然接上去，不会被截断。
- 删除了 tts.py 和所有 .mp3 缓存文件（已迁移到 .m4a 缓存）。
