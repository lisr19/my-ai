# 积分赛跑系统 - Vue 3 版本

这是一个基于 Vue 3 + Element Plus 的学生积分竞赛展示系统。

## 功能特性

- 📊 支持 Excel 文件导入学生数据
- 🎨 自定义背景图片
- ⚙️ 灵活的竞赛参数配置
- 🏆 实时排名显示
- 📱 响应式设计，支持移动端
- 🎬 流畅的动画效果

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 生产打包

```bash
npm run build
```

打包后的文件在 `dist` 文件夹中，可以直接在浏览器中打开 `dist/index.html` 使用。

## 使用说明

### 1. 导入数据

点击"选择Excel文件"按钮，选择包含学生数据的 Excel 文件。

Excel 文件需要包含以下列：
- `姓名` - 学生姓名
- `总分` - 学生总分
- `组` - 学生组别（可选，默认为 A）

### 2. 更换背景

点击"更换背景图片"按钮，选择一张图片作为竞赛区域的背景。

### 3. 配置参数

点击"竞赛配置"按钮，可以调整：
- 竞赛模式（全员到达终点 / 分层显示）
- 动画时长
- 头像大小
- 是否显示组别和分数
- 页面标题

### 4. 开始竞赛

点击"开始竞赛"按钮，选手将按照分数排名进行竞赛动画。

### 5. 查看排名

点击"查看排名"按钮，查看最终的排名结果。
