# 🏆 积分赛跑系统 — 使用说明

> 版本：v1.0 ｜ 更新日期：2026-08-28
> 一款学生积分竞赛可视化展示工具：导入成绩表，一键生成"赛跑动画 + 实时排名"，适合课堂公布成绩、班会激励、家长会展示等场景。
>
> 🎬 **视频演示**：项目根目录 `积分赛跑系统使用演示.webm`（约 1 分钟，含导入成绩、竞赛配置、开始竞赛、查看排名、学生详情完整流程），双击即可播放。

## 一、快速上手（3 步出效果）

### 第 1 步：打开系统

双击打开 `dist/index.html`（打包后的成品）即可，无需联网、无需安装。

> 首次使用或更新代码后，需要先构建一次，见 [五、安装与打包](#五安装与打包)。

### 第 2 步：导入成绩

1. 点击左上角 **「📂 导入Excel」**；
2. 选择按下方格式准备好的成绩表（项目自带 `public/成绩导入模板.xlsx`，可直接填用）；
3. 提示"成功导入 N 条学生数据"，赛道上即出现全部选手。

**Excel 格式要求**（第一行列名，第二行起为数据）：

| 列名 | 必填 | 说明 |
|------|:---:|------|
| 姓名 | ✅ | 学生姓名，用于标签和头像匹配 |
| 总分 | ✅ | 数字，决定赛跑速度/终点位置和排名 |
| 组 / 组别 / 分组 | ⬜ 可选 | 如 A、B、C、D（或"A组"），勾选"显示组别"后按组配色 |

> ✏️ 也可以直接把成绩粘贴到 `public/成绩导入模板.xlsx` 里使用。
> 📷 `public/img/` 内已按学生姓名放置头像图片（如 `张卓琪.jpg`）的会被自动匹配。

### 第 3 步：开始竞赛

点击 **「开始竞赛」**，全体选手从起跑线同时出发：

- **全员到达终点模式**：分数越高跑得越快，冲线顺序即名次；
- **分层显示模式**：所有选手同时到达，分数越高位置越靠近终点。

动画结束后自动弹出排名榜，也可随时点击 **「查看排名」** 手动查看。

## 二、界面按钮说明

| 按钮 | 作用 |
|------|------|
| 📂 导入Excel | 上传 `.xlsx / .xls` 成绩表，自动生成选手 |
| 🖼 更换背景 | 上传任意 jpg/png 图片替换赛道背景（如教室照片、运动会主题图） |
| ⚙️ 竞赛配置 | 打开参数配置弹窗（见下表），配置自动保存，刷新不丢失 |
| 📘 使用说明 | 系统内置的简要说明（与本文档内容一致） |
| ▶ 开始竞赛 | 播放赛跑动画，可反复点击重新比赛 |
| 🏆 查看排名 | 打开排名抽屉，按分数从高到低展示全部选手 |

**排名榜小技巧**：点击任意学生行，可打开该学生的详情卡片（头像、组别、总分、排名）。

## 三、竞赛参数配置（⚙️）

| 配置项 | 说明 | 默认/范围 |
|--------|------|-----------|
| 页面标题 | 投屏时的大标题，如"802 班月度积分竞赛" | 总分竞赛 |
| 竞赛模式 | 全员到达终点（比速度）/ 分层显示（比位置） | 全员到达终点 |
| 显示组别 | 开启后不同组别选手标签配色不同 | 关 |
| 显示分数 | 是否在标签上显示总分 | 开 |
| 头像显示 | 默认头像 / 姓名匹配个人头像 / 姓氏 / 自定义头像 | 姓名匹配 |
| 上传自定义头像 | 选"自定义头像"后出现，全班共用一张头像 | — |
| 最快/最慢选手时长 | 仅"全员到达终点"模式：第 1 名与最后一名的跑完秒数 | 1-30 / 5-50 秒 |
| 动画时长 | 仅"分层显示"模式：整体动画秒数 | 1-30 秒 |
| 头像大小 | 赛道上头像圆圈的尺寸 | 30-100 像素 |
| 标签字体大小 | 姓名标签字号 | 8-20 像素 |
| 🔊 音效 | 开关出发/冲线音效 | 开 |
| 自定义音乐 | 上传 mp3 等音频作为竞赛背景音乐，可"清除" | — |
| 重置配置 | 恢复全部参数为默认值（有二次确认） | — |

## 四、常见问题

**Q1：头像是怎么显示的？**
按优先级依次尝试：① `public/img/` 下与姓名同名的图片（如 `张三.png / 张三.jpg`）→ ② 配置中选择的默认/姓氏/自定义头像。新加头像图片后重新打包即可生效。

**Q2：如何添加学生头像？**
把图片放入 `public/img/`，以学生姓名命名（支持 jpg/png/jpeg），重新执行 `npm run build`。

**Q3：导入后没有反应？**
检查 Excel：第一行必须是列名（姓名、总分），"总分"列必须是数字，不要合并单元格。

**Q4：想投屏到教室大屏？**
直接用浏览器全屏（F11）打开即可；建议提前调大"头像大小"和"标签字体大小"。

**Q5：配置改乱了怎么办？**
竞赛配置弹窗 → 左下角「重置配置」→ 确认后恢复默认。

**Q6：可以分享给其他老师用吗？**
可以。把整个 `dist` 文件夹拷给对方，双击其中的 `index.html` 就能用；也可以把项目里的 zip 包直接分发。

**Q7：数据会上传到网上吗？**
不会。所有数据在本地浏览器内处理，完全离线可用。

## 五、安装与打包（首次/更新代码时）

需要 Node.js ≥ 14。

```bash
cd 积分比赛
npm install        # 安装依赖（仅需一次）
npm run build      # 打包，产物在 dist/
```

之后双击 `dist/index.html` 使用。日常使用无需再打包。

开发调试（改代码实时预览）：

```bash
npm run dev        # 浏览器打开提示的 http://localhost:5173
```

## 七、推荐使用流程（课堂场景）

1. 课前：更新 Excel 成绩 → `npm run build` → 打开 `dist/index.html`；
2. 课上：导入 Excel →「竞赛配置」改标题、选"姓名匹配个人头像" → F11 全屏；
3. 公布：点「开始竞赛」播放动画，音乐响起，学生冲线；
4. 总结：点「查看排名」逐名点评，点击学生卡片查看详情；
5. 彩蛋：换一张背景图（如运动会照片），换个模式再来一轮。
