## 📝 使用说明

### 1. 导入数据
- 点击"选择Excel文件"
- 选择包含学生数据的 Excel 文件
- Excel 需要包含 `姓名`、`总分`、`组` 三列

### 2. 配置参数（可选）
- 点击"竞赛配置"
- 调整竞赛模式、动画时长等
- 点击"保存配置"

### 3. 开始竞赛
- 点击"开始竞赛"按钮
- 观看选手竞赛动画

### 4. 查看排名
- 点击"查看排名"查看最终结果

## 🎨 自定义选项

在"竞赛配置"中可以调整：

| 选项 | 说明 |
|------|------|
| 竞赛模式 | 全员到达终点 / 分层显示 |
| 最快/最慢时长 | 动画时长范围 |
| 出发延迟 | 选手出发间隔 |
| 头像大小 | 选手头像尺寸 |
| 标签字体 | 姓名标签字体大小 |
| 显示组别 | 是否显示学生组别 |
| 显示分数 | 是否显示学生分数 |
| 页面标题 | 自定义页面标题 |

## 🖼️ 添加学生头像

1. 将头像图片放在 `public/img/` 文件夹
2. 命名为学生姓名，如 `张三.png`
3. 支持格式：jpg, png, jpeg
4. 重新打包：`npm run build`
