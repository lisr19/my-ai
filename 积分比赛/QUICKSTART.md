# 快速开始指南

## 📦 安装和运行

### 方式一：开发模式（推荐用于开发）

```bash
cd vue-race-system
npm install
npm run dev
```

然后在浏览器中打开 `http://localhost:5173`

### 方式二：打包后本地使用（推荐用于生产）

```bash
cd vue-race-system
npm install
npm run build
```

打包完成后，在 `dist` 文件夹中找到 `index.html`，直接在浏览器中打开即可使用。

## 📋 使用步骤

1. **导入数据**
   - 点击"选择Excel文件"
   - 选择包含学生数据的 Excel 文件
   - Excel 需要包含 `姓名`、`总分`、`组` 三列

2. **配置参数**（可选）
   - 点击"竞赛配置"
   - 调整竞赛模式、动画时长等参数
   - 点击"保存配置"

3. **开始竞赛**
   - 点击"开始竞赛"按钮
   - 观看选手竞赛动画

4. **查看排名**
   - 点击"查看排名"查看最终结果

## 📊 Excel 文件格式

## 🎨 自定义

- **头像大小**：在配置中调整头像大小
- **显示选项**：在配置中选择是否显示组别和分数

## 🐛 常见问题

**Q: 打包后如何使用？**
A: 运行 `npm run build`，然后在浏览器中打开 `dist/index.html` 即可。

**Q: 如何修改页面标题？**
A: 点击"竞赛配置"，修改"页面标题"字段。

**Q: 支持多少个学生？**
A: 理论上无限制，但建议不超过 100 个以保证性能。

**Q: 如何添加学生头像？**
A: 将头像图片放在 `public/img/` 文件夹中，命名为学生姓名（如 `张三.png`）。
