# Excel 自动处理工具 - 需求文档

## 1. 项目概述

### 1.1 项目名称
Excel 自动处理工具 (Excel Processor)

### 1.2 项目目标
开发通用的 Excel 文档自动处理工具，支持导入 Excel、按预设模板进行统计分析、输出格式化的 Excel 报告。面向班级管理场景（积分统计、成绩分析等）。

### 1.3 项目位置
`/Volumes/D盘/my-ai/excel-processor/`

## 2. 实际数据结构

基于参考文件「初二2班学生积分实时更新表(2026.5.17).xlsx」分析：

### 2.1 文件信息
- 学校：珠海市礼和中学
- 班级：初2024级2班
- 总人数：43名学生
- 小组数：12个小组（第一组~第十二组）
- 每组人数：2~4人不等

### 2.2 Excel 结构
| 列范围 | 内容 | 说明 |
|--------|------|------|
| A列 | 组别 | 合并单元格，如A3:A6="第一组" |
| B列 | 姓名 | 学生姓名 |
| C~Z列 | 积分项 | 24个积分项，无表头，数值类型（含负数） |
| AA列 | 个总 | 个人总分（原表已计算） |
| AB列 | 组总 | 小组总分（合并单元格） |
| AC列 | 人均 | 小组人均分（合并单元格） |
| AD列 | 组排 | 小组排名（合并单元格） |
| AE列 | 排名 | 全班排名 |

## 3. 功能需求

### 3.1 积分统计模板 (score_stats) ✅ 已实现

#### 输出统计内容
1. **个人总分**：每个学生24个积分项的加总
2. **小组总分**：小组所有成员个人总分之和
3. **小组平均分**：小组总分 ÷ 小组人数（保留2位小数）
4. **小组排名**：按小组总分从高到低排名
5. **个人全班排名**：按个人总分从高到低排名
6. **个人组内排名**：个人在所在小组内的排名

#### 输出 Excel 结构（3个Sheet）
- **Sheet 1 - 个人明细统计**：按小组分组展示，含原始积分 + 个人总分 + 全班排名 + 组内排名
- **Sheet 2 - 小组汇总统计**：排名 + 小组名称 + 人数 + 总分 + 平均分 + 与第一名差距
- **Sheet 3 - 排行榜**：全班排行榜（前3名金银铜高亮）+ 各小组第一名

### 3.2 成绩分析模板 (grade_stats) ✅ 已实现
- 个人总分/平均分
- 小组各科平均分
- 分数段统计（优秀/良好/中等/及格/不及格）
- 排名统计

## 4. 技术方案

### 4.1 技术栈
- Python 3.13 + openpyxl

### 4.2 核心模块
- `excel_reader.py`：读取Excel、解析合并单元格、提取分组数据
- `statistics.py`：统计计算（总分、平均分、排名）
- `excel_writer.py`：生成格式化Excel（多Sheet、样式、条件格式）
- `main.py`：CLI入口

### 4.3 使用方式
```bash
python main.py --input 积分表.xlsx --template score_stats --output 结果.xlsx
python main.py --input 积分表.xlsx --auto --output 结果.xlsx
```
