# 🪄 智能表单自动填充插件

一个 Chrome/Edge 浏览器扩展，可以一键自动填写网页表单（特别是针对 Element UI 的表单）。

## ✨ 功能特性

1. **一键自动填充** - 点击按钮或浮动按钮即可自动填写整个表单
2. **智能字段匹配** - 自动识别表单字段类型并匹配对应数据
3. **数据模板管理** - 保存多套数据模板，快速切换
4. **兼容 Element UI** - 支持 Vue + Element UI 组件的表单
5. **页面浮动按钮** - 无需打开弹窗，直接在页面上操作

## 📦 安装方法

### Chrome 浏览器

1. 打开浏览器地址栏输入 `chrome://extensions/`
2. 开启右上角 **"开发者模式"**
3. 点击 **"加载已解压的扩展程序"**
4. 选择 `auto-form-filler` 文件夹
5. 插件安装完成！

### Edge 浏览器

1. 打开 `edge://extensions/`
2. 开启开发者模式 → 加载解压缩的扩展
3. 选择本文件夹

## 🎯 使用方法

### 方式一：使用弹出面板

1. 点击浏览器工具栏的插件图标
2. 在「数据配置」标签页填写表单数据
3. 点击「保存配置」保存为模板
4. 在「快速操作」标签页点击「✨ 自动填写」

### 方式二：使用页面浮动按钮

安装后每个网页右下角会出现一个**紫色圆形按钮**：

| 按钮 | 功能 |
|------|------|
| 📝 自动填写 | 用当前保存的数据填充表单 |
| 🗑️ 清空表单 | 清除所有表单字段 |
| 💾 保存当前 | 将当前表单内容保存为模板 |

## 🔧 支持的表单字段

根据你提供的截图，插件支持以下字段的自动填写：

### 合同基本信息
- 合同名称 (文本)
- 审核流程 (下拉选择)

### 签约主体 - 基础信息
- 甲方名称 (下拉选择/文本)
- 证件类型 (下拉选择)
- 证件号码 (文本)
- 法定代表人 (文本)
- 联系电话 (文本)
- 注册地址 (省市区级联选择)
- 详细地址 (文本)

### 联系人信息
- 联系人 (文本)
- 联系方式 (文本)
- 证件类型 (下拉选择)
- 证件号码 (文本)

## ⚠️ 注意事项

1. 首次使用需要先在「数据配置」中填写测试数据并保存
2. 如果页面是 SPA 应用（如 Vue/React），确保页面完全加载后再操作
3. 对于级联选择器（如省市区），可能需要手动触发或调整延迟时间
4. 下拉选择框的匹配依赖选项文字包含关系

## 🔨 自定义开发

如需支持更多字段，编辑 `autoFiller.js` 中的 `buildFieldMapping()` 函数：

```javascript
function buildFieldMapping() {
  return {
    // 添加新的字段映射
    yourField: ['input[placeholder*="你的占位符"]', 'input[name*="yourField"]']
  };
}
```
